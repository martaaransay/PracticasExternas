IntegronFinder2

IntegronFinder2 identifica integrones en secuencias de DNA y acota las regiones de los Pc (que es lo que nos interesa) en los integrones encontrados

Uso del comando en bash:

integron_finder [-h] [--local-max] [--func-annot] [--cpu CPU] [-dt DISTANCE_THRESHOLD] 
                [--outdir OUTDIR] [--union-integrases] [--cmsearch CMSEARCH] 
                [--hmmsearch HMMSEARCH] [--prodigal PRODIGAL] [--path-func-annot PATH_FUNC_ANNOT] 
                [--gembase] [--gembase-path GEMBASE_PATH] [--annot-parser ANNOT_PARSER] 
                [--prot-file PROT_FILE] [--attc-model ATTC_MODEL] [--evalue-attc EVALUE_ATTC] 
                [--calin-threshold CALIN_THRESHOLD] [--keep-palindromes] [--no-proteins]
                [--promoter-attI] [--max-attc-size MAX_ATTC_SIZE] [--min-attc-size MIN_ATTC_SIZE] 
                [--eagle-eyes] [--pdf] [--gbk] [--keep-tmp] [--split-results] [--circ | --linear] 
                [--topology-file TOPOLOGY_FILE] [--version] [--mute] [-v] [-q] replicon
ImportantArgumentos que acepta IntegronFinder2

He marcado en azul aquellos argumentos que pueden tener sentido para la búsqueda y clasificación de Pcs:

positional arguments:

  • replicon: Path to the replicon file (in fasta format), eg : path/to/file.fst or file.fst

optional arguments:

  • -h, –help: show this help message and exit

  • –local-max: Allows thorough local detection (slower but more sensitive and do not increase false positive rate).

  • –func-annot: Functional annotation of CDS associated with integrons HMM files are needed in Func_annot folder.

  • –cpu CPU: Number of CPUs used by INFERNAL and HMMER. Increasing too much (usually above 4) may decrease performance.

  • -dt DISTANCE_THRESHOLD, –distance-thresh DISTANCE_THRESHOLD: Two elements are aggregated if they are distant of DISTANCE_THRESH [4000]bp or less

  • –outdir OUTDIR: Set the output directory (default: current)

  • –union-integrases: Instead of taking intersection of hits from Phage_int profile (Tyr recombinases) and integron_integrase profile, use the union of the hits. Es decir, IntegronFinder no detecta la Int con un solo modelo, sino combinando dos perfiles HMM distintos, luego se mantiene la intersección de ambos modelos para ser detectado

De estos siguientes no hay que modificar nada porque hemos instalado el entorno completo:

  • –cmsearch CMSEARCH: Complete path to cmsearch if not in PATH. eg: /usr/local/bin/cmsearch

  • –hmmsearch HMMSEARCH: Complete path to hmmsearch if not in PATH. eg: /usr/local/bin/hmmsearch

  • –prodigal PRODIGAL: Complete path to prodigal if not in PATH. eg: /usr/local/bin/prodigal

  • –path-func-annot PATH_FUNC_ANNOT: Path to file containing all hmm bank paths (one per line)

Los siguientes son alternativas para no usar PRODIGAL y usar otro fichero de proteínas ya anotado:

  • –gembase: Use gembase formatted protein file instead of Prodigal. Folder structure must be preserved

  • –gembase-path GEMBASE_PATH: path to the gembase root directory (needed only if the replicon file is not locatedin gembase-path)

  • –annot-parser ANNOT_PARSER: the path to the parser to use to get information from protein file.

  • –prot-file PROT_FILE: The path to the proteins file used for annotations

  • –attc-model ATTC_MODEL: Path or file to the attc model (Covariance Matrix).

  • –evalue-attc EVALUE_ATTC: Set evalue threshold to filter out hits above it (default: 1) Un valor más bajo es más estricto (ahora es E-value)

  • –calin-threshold CALIN_THRESHOLD: keep ‘CALIN’ only if attC sites number >= calin-threshold (default: 2) Un CALIN es un cluster de sitios attC que aparecen juntos sin una Int cercana asociada. El default exige que haya al menos 2 attC juntos para que sea CALIN

  • –keep-palindromes: For a given hit, if the palindromic version is found, don’t remove the one with highest evalue. Los attC son repeticiones invertidas imperfectas, así que a veces se encuentran hits prácticamente en la misma posición en ambas hebras. Por defecto, se queda solo con el mejor de los dos (menor e-value)

  • –no-proteins: Don’t annotate CDS and don’t find integrase, just look for attC sites. No debemos usarlo porque anota el pc en relación a la posición de la Integrasas

  • –promoter-attI: Search also for promoter and attI sites. (default False)

  • –max-attc-size MAX_ATTC_SIZE: Set maximum value fot the attC size (default: 200bp)

  • –min-attc-size MIN_ATTC_SIZE: Set minimum value fot the attC size (default: 40bp)

  • **–eagle-eyes: Synonym of –local-max. Like a soaring eagle in the sky, catching rabbits (or attC sites) by surprise.
